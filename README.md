# CodeLIB
The Collaboration for the CodeLIB Project

NAME: Code{LIB}
TEAM: (REPO ADMIN) Levi Herridge, Seth McGaughy, Kalyb Kirby
AUDIENCE: General coders of all skill levels, beginner to advanced

PURPOSE: A dedicated library of functional code snippets that can be referenced to either be stored for later use and reference; or to gather inspiration for projects from other people's libraries. You should be able to not only create and manage your own libraries but also search the database for other people's entries. The app should be easy to navigate and simple to understand and use effectively.

PAGE MAP

HOME PAGE: Should be the main landing page of the app, has a large search bar and graphics, along with some simple javascript implementations to fill the page.
SEARCH PAGE: An advanced search page that has the ability to change filters based on tags, and can be used to find exactly what you are looking for. (CHILD PAGE: Search result page)
MY-ENTRY’S PAGE: The main template that allows you to manage your created pages by creating new ones, editing current ones, and deleting ones no longer needed (CHILD PAGES: Create Page, Edit Page, Delete Page)
HELP PAGE: Allows you to reach out to the development team in case of an issue with site functionality, allowing for feedback and bug reports.
ACCOUNT CREATION PAGE: Allows users to create and manage their accounts, and have the database store all user information.

INFORMATION

The Home page is critical as the landing page for the whole website, along with being the anchor form that holds the site together. In this case when the user submits the form they either do a simple keywords search or click on a recent post.
The site will only ask for information that is important for account creation and login, to distinguish and individualize each user’s account. 
The Advanced Search pages are important as it allows any user to find exactly what they are looking for by using specific tags. The form submits when the search button is pressed and the database retrieves the tagged content.
The accessibility features will allow a user to fully scroll and tab through the webpages and be able to select options fully with keyboard support.
The My-Entries pages lets a user manage what they have already posted on the app, while also allowing for new entries to be made using a separate form for the text editor. The form is completed via use of its child forms that can be used for Creation, Editing, and Deletion.
